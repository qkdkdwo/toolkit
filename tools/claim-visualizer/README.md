# 청구항 분해·시각화 도구 (Claim Visualizer)

특허 청구항을 붙여 넣으면 구조를 나누고 구성요소 사이의 관계를 시각화하는 브라우저 도구입니다.
HTML 파일 하나로 동작하며 서버나 설치가 필요 없습니다.

## 기능

1. **청구항 분리**: `【청구항 N】`, `청구항 N`, `1.`, `Claim 1:`, `【請求項1】`, `权利要求1.` 형식을 인식합니다.
2. **독립항·종속항 구분**: 인용 청구항을 찾아 인용관계 트리로 보여 줍니다. `제1항 내지 제3항`, `claims 1 to 3` 같은 범위 인용도 처리합니다.
3. **구조 분해**: 전제부, 연결부(포함하는, comprising, 其特征在于, を備える 등), 본문, 종결부로 나눕니다.
4. **권리범위 표현 강조**: `및/또는`, `중 적어도 하나`, `복수의`, `상기`, `at least one of`, `plurality` 등을 표시합니다.
5. **구성요소 표**: 기호(a, b, c …, 청구항마다 a부터), 구성요소 이름, 기능·관계 키워드, 연결관계(A → B), O/△/X 검토, 메모 칸이 있습니다.
6. **연결관계도**: A → B(B가 A를 인용하거나 A와 연결·작용 관계에 있음)를 화살표로 그립니다.
7. **유형 주의·원문 불명확 표시**: 청구 대상(방법/장치)과 본문 구성이 맞지 않으면 `⚠ 청구항 유형 주의`를, 연결부나 구성요소 이름을 찾지 못하면 `(원문 불명확)`을 표시합니다.
8. **내보내기**: Markdown 복사, CSV 다운로드(Excel에서 한글이 깨지지 않음). CSV는 [청구항 구성요소 분석기 프롬프트](../../prompts/5_claim-component-analyzer/)의 입력으로 그대로 쓸 수 있습니다.

분해 기준, 화살표 정의, O/△/X 기준은 [청구항 분석 공통 기준](../../docs/claim-analysis-standard.md)을 따릅니다.

## 예시 청구항

화면의 예시 버튼과 `tests/`에 들어 있는 청구항은 모두 이 저장소를 위해 새로 작성한 가상 청구항이며, 실제 특허 문헌을 옮기거나 변형한 것이 아닙니다.

## 지원 언어

한국어, 영어, 일본어, 중국어 (자동 판별)

## 한계

- AI가 아니라 문장 규칙으로 분해합니다. 표현이 특이한 청구항에서는 구성요소의 경계와 이름이 틀릴 수 있으므로, 결과는 반드시 사람이 검토해야 합니다.
- 침해·무효·등록 가능성을 판단하지 않습니다.

## 구조

- `<script id="core">`: 분석 로직 (DOM과 무관한 순수 함수, Node.js에서 테스트 가능)
- 두 번째 `<script>`: 화면 표시와 내보내기
