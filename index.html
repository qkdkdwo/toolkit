Patent Analysis Toolkit

특허 조사·분석 실무에서 반복해서 쓰는 도구, 프롬프트, 분석 기준을 모아 둔 곳입니다.

바로 쓰는 도구

브라우저 도구 청구항 분해·시각화 청구항을 붙여 넣으면 구조 분해, 구성요소 표(O/△/X), 연결관계도, CSV 내보내기를 제공합니다. 입력 내용은 외부로 전송되지 않습니다. 결과 예시 핵심특허 청구항 분석 예시 핵심특허 청구항 분석기 프롬프트로 만드는 결과 화면을 가상 청구항(스테이플러)으로 채운 예시입니다.

프롬프트 (Claude·ChatGPT 공용)

청구항 구성요소 분석기 과제 기술과 청구항을 대비해 구성요소·기능·연결관계와 O/△/X, 검토의견을 정리합니다. 핵심특허 청구항 분석기 전체 청구항 대비표, 공통점·차이점, 침해 리스크·회피설계 의견을 HTML 템플릿으로 출력합니다.

기준 문서

특허 분석 공통 원칙 사실과 근거, IPC/CPC·검색 키워드, 선행기술 대비, Excel 요약, 검증 원칙 청구항 분석 공통 기준 4단계 구조 분해, 구성요소 기호(a, b, c), 연결관계 표기, O/△/X 기준
