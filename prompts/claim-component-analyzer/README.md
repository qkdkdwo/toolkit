# 청구항 구성요소 분석기 프롬프트

청구항을 구성요소로 분해하고, 과제 기술과의 대응(O/△/X)과 검토의견을 단일 HTML 파일로 정리하는 프롬프트입니다.
분석 기준은 [청구항 분석 공통 기준](../../docs/claim-analysis-standard.md)을 따릅니다.

## 사용 방법

1. `prompt.md` 본문을 AI 서비스의 프로젝트 지침(Claude 프로젝트, ChatGPT 프로젝트·GPTs 등)에 붙여 넣습니다.
2. 대화에 과제 기술 설명과 청구항 원문을 넣습니다.
3. (선택) [청구항 분해·시각화 도구](https://qkdkdwo.github.io/toolkit/tools/claim-visualizer/)에서 내려받은 CSV를 함께 넣으면, 그 분해 결과를 출발점으로 분석합니다.

## 결과물

- 단일 HTML 파일: 구조 분해, 구성요소 카드(기능·연결관계·O/△/X), 핵심 특징 요약, 검토의견
- 대화 본문의 검토의견 3~5문장

## 주의

- 기술적 대응 여부만 다루며 침해·무효·권리범위 판단은 하지 않습니다.
- 결과는 반드시 사람이 원문과 대조해 검토해야 합니다.

## 변경 이력
