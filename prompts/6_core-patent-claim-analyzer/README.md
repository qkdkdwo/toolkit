# 6. 핵심특허 청구항 분석기 프롬프트

기업 보유 기술과 핵심특허 청구항을 대비해, 전체 청구항 대비표(O/△/X), 대표청구항 구성요소 시각화, 공통점·차이점, 전략 의견(침해 리스크, 회피설계, 개량 방안)을 단일 HTML 파일로 정리하는 프롬프트입니다.
분석 기준은 [청구항 분석 공통 기준](../../docs/claim-analysis-standard.md)을 따르며, 검토의견은 기준 7장 B(전략 의견)에 해당합니다.

## 파일

| 파일 | 내용 |
|---|---|
| `prompt.md` | 프롬프트 본문 (프로젝트 지침에 붙여 넣기) |
| `template.html` | 출력 HTML 템플릿 (프로젝트 파일로 첨부) |
| `example-output.html` | 가상 청구항과 가상 기업 기술로 채운 결과 예시 (실제 특허·기업 아님) |

## 사용 방법

1. `prompt.md` 본문을 AI 서비스의 프로젝트 지침(Claude 프로젝트, ChatGPT 프로젝트·GPTs 등)에 붙여 넣습니다.
2. `template.html`을 같은 프로젝트에 파일로 첨부합니다.
3. 대화에 기업 보유 기술, 특허 청구항, (권장) 발명의 설명을 넣습니다.
4. (선택) [청구항 분해·시각화 도구](https://qkdkdwo.github.io/toolkit/tools/claim-visualizer/)에서 내려받은 CSV를 함께 넣으면 그 분해 결과를 출발점으로 분석합니다.

## 결과물 구성

1. 청구항 분석: 전체 청구항의 구성요소(a, b, c …)별 내용과 O/△/X 검토의견
2. 구성요소 시각화: 대표청구항의 구조 분해(전제부·연결부·본문·종결부)와 구성요소 카드
3. 청구항 기술 요약: 2줄 이하
4. 공통점 및 차이점
5. 검토 의견: 침해 리스크(문언·균등), 회피설계 방향, 개량 방안, 균등 침해 판단 해석 근거

## 주의

- 결과물 맨 아래에 "최종 법률 판단이 아님" 고지가 들어갑니다. 지우지 마세요.
- 결과는 반드시 사람이 원문과 대조해 검토해야 합니다.
